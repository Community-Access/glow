# AHG 2026 helpers' card

You are why nobody gets stuck and stays stuck. Read this once before 10:00.
Facilitators only; it is not in the kit.

## How to help

- Go to the person, not the projector. Look for whoever has not typed
  anything yet, and sit with them quietly.
- Never take the keyboard or the mouse. Say what to press, and wait.
- Describe, do not point. "The Copy button under Block 3" works for
  everyone; "that one there" works for nobody using a screen reader.
- Ask before you touch anyone's laptop, braille display or chair.
- Let the screen reader finish speaking before you talk.
- Never ask for, read out or repeat anything private: student names,
  records, accommodation details. If you see any on a screen, ask the person
  to remove it from the chat.
- Every step has a finished version in `examples/`. Starting from a
  ready-made agent counts, and it still goes in with their name on it. Say
  so.

## What to watch for, block by block

Each row is one block of the day, what to watch for, and what to do.

| Block | Watch for | What to do |
|---|---|---|
| Setup, from 10:00 | No kit open, no sign-in, Restricted Mode banner | Manage, then Trust; sign in from the Accounts menu; if VS Code will not cooperate, move them to the browser path |
| 1. Why we are here | The ready check says "Needs a hand" | Fix that one step; the room carries on |
| 2. Design your agent | A blank chat after five minutes | Offer the ready-made agent nearest their card, in `examples/agents/` |
| 3. Your agent at work | Worry that the agent guessed | Say the guessing is the point: it is what block 4 fixes |
| 4. Ground it | The agent cites no criterion | Check it read the right file in `sample-course/evidence/`; run /ground-my-agent again |
| 5. Build the office | The run stops part way | Type "continue"; on the browser path, paste their agent again |
| 6. Share it | A "Nearly there" reply, or an issue labelled needs-a-hand | Read the reply with them: it says exactly what to fix; edit the issue and save |
| 7. Take it home | Plans that are too big | "Run it on the next five requests" beats "transform our office" |

## The three fallbacks

1. Copilot Free limit reached, or VS Code will not work: the browser path,
   from the same block, at letitglow.app/ahg/assistant. Their agent goes
   with them.
2. An assistant forgets their agent: paste the agent as its own message,
   then the block's text again.
3. GitHub unreachable in block 6: copy their agent file to the USB stick at
   the front. It is shared for them after the session, credited to them.

## Needs a hand

Shares that fail get the label needs-a-hand on
github.com/Community-Access/ahg-2026/issues. Check it at the start of block
6 and every ten minutes after. Go to those people first.

## What not to say

- "It's easy" or "just". If it were easy for them, they would not need you.
- "Compliant" or "accessible" about any document. Say what was checked.
- Anything that suggests a screen reader user should switch paths because
  of their screen reader. Every path works with one.
