# Workshop Exercises Pack

This pack maps directly to conference delivery and can be used in guided
forms, printable worksheets, or facilitator-led group practice.

**Times are suggestions, and they come from one place.** The activity pages,
the agenda, the deck and this pack all show the same number, because all four
read it from the same definition. Nobody is behind if they take longer.

*Maintainers: the definition is `workshop_agenda.py`, and a test fails if
these drift apart.*

Eleven activities carry the progress passport. The optional lab at the end
does not, on purpose: a participant who never opens it has missed nothing the
workshop promised.

## Exercise 1: Accessibility Journey Check-In
- Time: 20 minutes
- Purpose: establish participant context and partner barriers.
- Output: journey notes and shared challenge map.

## Exercise 2: What Problem Are We Solving?
- Time: 30 minutes
- Purpose: move from tool-first thinking to problem-first framing.
- Output: problem statement with capacity-building target.

## Exercise 3: Fix It for Me vs Teach Me to Improve It
- Time: 30 minutes
- Purpose: practice coaching language that solves now and teaches next time.
- Output: reusable coaching response examples.

## Exercise 4: Helpful, Risky, or Human Required
- Time: 30 minutes
- Purpose: classify tasks by responsible AI boundary.
- Output: AI boundary map with safeguards.

## Exercise 5: Accessibility Agent Formula
- Time: 35 minutes
- Formula: Role + Task + Trusted Guidance + Output Format + Human Review
- Output: first non-technical accessibility agent concept.

## GLOW Lab 1: Accessible Communications
- Time: 45 minutes
- Focus: plain language, structure, meaningful links, inclusive access language.
- Output: revised communication and review checklist.

## GLOW Lab 2: Alt Text and Human Judgment
- Time: 45 minutes
- Focus: image purpose, relevant details, omission decisions, verification.
- Output: image-description coaching checklist.

## GLOW Lab 3: Remediation Planning
- Time: 45 minutes
- Focus: prioritization, owner coaching, realistic sequencing.
- Output: remediation coaching template.

## Accessibility Champion Studio
- Time: 40 minutes
- Focus: build a reusable partner-facing workflow.
- Output: draft champion workflow artifact.

## Peer Review and Refinement
- Time: 15 minutes
- Focus: strengthen trust, safeguards, and reuse quality.
- Output: revised workflow and scaling path.
- **Not a numbered activity.** There is no `/w/<code>/` address for this
  round. Peer feedback is a form attached to each submission in the shared
  gallery, so send the room to the gallery and give them the three sentences
  below.
- One strength, one risk or missing safeguard, one way to reuse it elsewhere.

## Capstone Share-Out
- Time: 15 minutes
- Focus: say the workflow out loud in four sentences, then assemble the
  take-home artifact.
- Output: capstone summary and a printable artifact.

## 30-Day Action Plan
- Time: 10 minutes
- Focus: commitment to operational follow-through.
- Output: 30-day plan with one workflow, one partner, one safeguard, one next
  step.

## Optional Lab: Run Your Agent
- Time: 20 minutes, optional, and outside the agenda.
- Focus: actually run the agent designed in Exercise 5, in whatever assistant
  the participant already has.
- Output: notes on what it got right, what it got wrong, and what they would
  change about their own design.
- Mention it once, at the end of Exercise 5. A door, not a corridor.
