# Step card 0: Before the day

About 25 minutes, any time before 16 November. Everything starts at
letitglow.app/ahg.

## What you will have at the end

A laptop that is ready for the whole workshop, a message from Copilot
saying so, and your practice agent already shared, so sharing on the day is
the second time, not the first.

## Steps

1. Make a free GitHub account at github.com. Use your work email if your
   institution allows it. If GitHub asks you to set up two-factor
   sign-in, choose the option that works best with your screen reader or
   phone; GitHub Mobile and an authenticator app both work.
2. Turn on Copilot Free: on github.com, open Settings, then Copilot, and
   choose the free plan.
3. Install VS Code from code.visualstudio.com. On Windows it installs
   without administrator rights.
4. Open VS Code, and sign in to GitHub when it asks, or from the Accounts
   button.
5. Import the AHG 2026 profile: open the Command Palette with Control+Shift+P
   on Windows or Command+Shift+P on a Mac, type Profiles: Import Profile, and
   paste the profile address from letitglow.app/ahg. VS Code asks whether to
   import it; say yes. It installs everything else and makes the text larger.
6. Download the agent kit from letitglow.app/ahg, unzip it, and open the
   folder in VS Code: File, then Open Folder. If VS Code asks whether you
   trust the folder, say yes; it is the workshop kit.
7. Open Copilot Chat: Control+Alt+I on Windows, or Command+Control+I on a
   Mac. Type /ready-check and press Enter.
8. Share your practice agent. In your browser, open
   letitglow.app/ahg/share, choose "My practice agent", choose the file
   my-agent/SKILL.md from the kit, and press Open the share form on GitHub.
   On GitHub, tick the privacy box at the end of the form and press Submit
   new issue.

## You are on track if

Copilot ends the ready check with: You are ready for 16 November. And on
GitHub, within about a minute, a reply begins: Well done.

## If you are stuck

Write to support@community-access.org before the day, or come to the setup
table outside the room from 10:00 on the day. Locked-down laptop, or GitHub
blocked at work? Write to us; nobody is left out.

## Your win

You are set up, and you have already shared an agent once. The hardest part
of the day is done.
