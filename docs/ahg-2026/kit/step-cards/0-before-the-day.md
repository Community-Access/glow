# Step card 0: Before the day

About 20 minutes, any time before 16 November.

## What you will have at the end

A laptop that is ready for the whole workshop, and a message from Copilot
saying so.

## Steps

1. Make a free GitHub account at github.com. Use your work email if your
   institution allows it.
2. Turn on Copilot Free: on github.com, open Settings, then Copilot, and
   choose the free plan.
3. Install VS Code from code.visualstudio.com. On Windows it installs
   without administrator rights.
4. Open VS Code, and sign in to GitHub when it asks, or from the Accounts
   button.
5. Import the AHG 2026 profile from the link in your setup email. VS Code
   asks whether to import it; say yes. It installs everything else and makes
   the text larger.
6. Download the agent kit, unzip it, and open the folder in VS Code: File,
   then Open Folder. If VS Code asks whether you trust the folder, say yes;
   it is the workshop kit.
7. Open Copilot Chat: Control+Alt+I on Windows, or Command+Control+I on a
   Mac. Type /ready-check and press Enter.

## You are on track if

Copilot ends with: You are ready for 16 November.

## If you are stuck

Write to support@community-access.org before the day, or come to the setup
table outside the room from 10:00 on the day. Locked-down laptop? Write to
us; nobody is left out.

## Your win

You are set up. That was the hardest part of the day, and it is done.
