# Welcome to the AHG 2026 agent kit

You are in the right place. This page opens by itself when you open the kit
in VS Code. Nothing here needs code, and nothing here can break.

## What is in this folder

| Folder or file | What it is |
|---|---|
| `my-agent/SKILL.md` | Your agent. A plain-English template with six headings: Role, Task, Trusted guidance, Output format, Human review, Never. You fill it in |
| `sample-course/` | PSY 101, the course everyone works on. Every file has barriers planted on purpose |
| `office-team/` | The ready-made accessibility office: a coordinator and its specialists, from the Accessibility Agents project |
| `examples/` | Three finished agents, one per role card, with what they produced. Start from one of these, not from a blank page |
| `.vscode/` | Settings that make VS Code larger and friendlier to screen readers. You do not need to open it |

## Where to start

1. Open `examples/` and read the example for your role card.
2. Open `my-agent/SKILL.md`, and replace each part with your answers. Copying
   from the example is encouraged.
3. Open Copilot Chat: press Control+Alt+I on Windows, or Command+Control+I on
   a Mac. Then follow the step card for this block.

## Keys worth knowing

| To | Windows | Mac |
|---|---|---|
| Open Copilot Chat | Control+Alt+I | Command+Control+I |
| Find any command | Control+Shift+P | Command+Shift+P |
| Move between parts of the window | F6 | F6 |
| Accessibility help for where you are | Alt+F1 | Option+F1 |
| Save | Control+S (it also saves on its own) | Command+S |

## If you are stuck

Raise a hand. A helper comes to you. Every step has a finished version in
`examples/`, so you can always catch up and keep going.

## The two rules

1. Never paste anything private into any AI: student records, health or
   disability information, or anyone's name. Use the sample course.
2. Every agent ends with a person checking its work. Yours too.
