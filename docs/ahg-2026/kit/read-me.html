Welcome to the AHG 2026 agent kit

You are in the right place. This page opens by itself when you open the kit in VS Code. Nothing here needs code, and nothing here can break.

Three paths into the same day

Every path gives you the same agent, the same team report and the same share on GitHub. letitglow.app/ahg/paths compares them.

  • In a browser: no kit needed. Open letitglow.app/ahg/assistant, copy each block's text, and paste it into ChatGPT, Copilot on github.com, Claude, Gemini or your campus assistant. The same texts are in this kit, in any-assistant/.
  • In VS Code on your computer: you are probably reading this there. Each block is one command in Copilot Chat.
  • In VS Code for the Web: the same, at vscode.dev in Chrome or Edge, with this folder opened from your laptop.

Start here, in VS Code

  1. Open Copilot Chat: Control+Alt+I on Windows, or Control+Command+I on a Mac.
  2. Type /ready-check and press Enter. Copilot checks six things and tells you that you are ready.

If a banner says Restricted Mode, choose Manage, then Trust first. It is the workshop kit, and Copilot cannot work on its files until you trust it.

Every block of the day has its own command, listed below, and its own step card in the step-cards folder.

You cannot fall behind

Every step has a finished version in examples/. If anything goes wrong, start from one of the six ready-made agents in examples/agents/, put your name on it, and carry on. That is still your agent, and it still goes into the open-source project with your name on it. If VS Code gives you trouble, switch to the browser path and carry on from the same block.

If you use a screen reader

Everything today works with NVDA, JAWS and VoiceOver, on every path.

  • In VS Code, Copilot's answers are long. Move to the answer and press Alt+F2 (Option+F2 on a Mac) to read it as plain text in the Accessible View. Inside it, Control+Alt+Page Down and Control+Alt+Page Up move between code blocks.
  • VS Code plays a sound when an answer arrives, and another when Copilot needs you to approve something, such as saving your agent file. Help: List Signal Sounds turns them on or off.
  • Alt+F1 (Option+F1) in the chat box opens accessibility help for chat. F6 moves between the parts of the window.
  • On the browser path, every block's text at letitglow.app/ahg/assistant has a Copy button. A message under the button says it is copied.
  • On GitHub's share form, everything is filled in for you. Move to the end of the form, select the check box that says your agent contains nothing private, then press Submit new issue. The reply appears on the same page in about a minute; press F5 if your screen reader does not announce it.
  • Step cards 3 and 5 say where the long answers are and how to read them.

Keys worth knowing

These work in every part of VS Code, on a computer and at vscode.dev.

To Windows Mac
Open Copilot Chat Control+Alt+I Control+Command+I
Read an answer as plain text, in the Accessible View: move to the answer, then press Alt+F2 Option+F2
Open any file by name Control+P Command+P
Find any command Control+Shift+P Command+Shift+P
Move between parts of the window F6 F6
Accessibility help for where you are Alt+F1 Option+F1

With a screen reader running, VS Code plays a sound when Copilot's answer arrives and another when Copilot needs you to approve something. The settings are accessibility.signals.chatResponseReceived and accessibility.signals.chatUserActionRequired. While Copilot works, it says what it is doing; accessibility.verboseChatProgressUpdates turns that off. The kit sets chat text to 18 point with chat.fontSize.

The two rules

  1. Never paste anything private into any AI: student records, health or disability information, or anyone's name. Use the sample course.
  2. Every agent ends with a person checking its work.

Help, before or after the day: support@community-access.org.
