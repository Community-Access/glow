# Words used today

One line for each word the step cards and the deck use. Read it before the
day if any of these is new. Nothing here needs code.

| Word | What it means today |
|---|---|
| Agent | A set of plain-English instructions that tells an AI assistant how to do one job, the way you would brief a new colleague |
| Skill | The file format an agent is written in. VS Code, GitHub Copilot, Claude Code, Codex and Gemini CLI all read it |
| `SKILL.md` | The one file that holds an agent: a short header, then the instructions |
| Header | The few lines at the top of `SKILL.md`, between two lines of three dashes: the agent's name, what it does, and who wrote it |
| Copilot Chat | The place in VS Code where you type to GitHub Copilot. Control+Alt+I on Windows, Control+Command+I on a Mac |
| Command | A word starting with a slash, like `/ready-check`, that you type into Copilot Chat to start one block of the day |
| Browser path | Doing the day in ChatGPT, Copilot on github.com, Claude, Gemini or your campus assistant, by pasting one text per block |
| Accessible View | A plain-text copy of Copilot's last answer that a screen reader reads line by line. Alt+F2 on Windows, Option+F2 on a Mac |
| Checker | A tool that finds barriers in a file: GLOW, axe, Accessibility Insights, or Word's, PowerPoint's and Acrobat's own checkers |
| Evidence | A checker's report, the text of a document, or what you tell the agent. An agent works only from evidence |
| Grounded | An agent that answers from evidence and cites WCAG 2.2, rather than guessing |
| WCAG 2.2 | The Web Content Accessibility Guidelines, the W3C standard every workshop agent cites by criterion number |
| Human review | The section of every agent that names who checks its work before anything goes out, and what they check |
| Version | Each time you change your agent by one thing, it gets the next number. You make versions 1 to 4 today |
| Specialist | An agent that does one kind of file or one kind of check, such as Word documents or plain language |
| Coordinator | The agent that sends each course file to the right specialists and writes one team report |
| The office | Today's team: the coordinator, eight specialists, and your agent |
| Accessibility Agents | The open-source project of 113 skills your agent joins at the end of the day. It is already in the kit |
| The collection | The AHG 2026 folder on GitHub where every shared agent goes, each one committed in its author's name |
| Open source | Work anyone may read, use and improve, here under the MIT licence |

## The two rules

1. Never paste anything private into any AI: student records, health or
   disability information, or anyone's name.
2. Agents draft. People decide. Every agent ends with a named person
   checking its work.
