# Your day at a glance

Choose one campus-approved path. Times are Mountain Time.

## Where to work

- Browser: keep the workshop page at letitglow.app/ahg/assistant and your
  assistant in separate tabs. Copy each prompt to the same conversation.
  Save each complete agent version on the workshop page: choose the matching
  "Version to save", then "Download this version". Keep agent-v1.md through
  agent-v4.md without replacing
  an earlier file. If asked to replace it, choose Cancel and use a different
  name or folder.
- VS Code on your computer or at vscode.dev: keep the kit open and use
  Copilot Chat. Your working agent is in `my-agent/SKILL.md`; earlier
  versions are in `my-agent/history/`. Reopen the saved files to check them.
- Sharing: use letitglow.app/ahg/share in block 6 only when public sharing
  is approved. Otherwise keep a reviewed copy and a next step locally.

## The seven stops

1. 10:30, ready check: set up your chosen path; a helper can get you unstuck.
2. 11:05, design: answer the questions and save your agent, version 1.
3. 11:45, try: test it without a report, review one change and save version 2.
4. 1:15, ground: use the same file's evidence, verify the answer and save
   version 3. Lunch is at 12:15.
5. 2:15, office: add your agent to a team, review the report and save
   version 4. The break starts at 2:05.
6. 3:05, share: review privacy and permission; share or record a later step.
7. 3:40, plan: make a draft, check it with a partner and save your final
   30-day plan. The commitment wall opens at 4:15.

Each step card has the detailed keys, expected result and recovery options.
Keep earlier versions. Never paste private information into an AI, and
have a person review every draft before it is used.

## What to keep before moving on

The following list names each output and its completion check.

- Ready check: save and reopen the practice file. An assistant saying
  "Ready" is not enough if you cannot find and read your saved copy.
- Block 2: agent-v1.md with one task, input, output and reviewer role.
- Block 3: agent-v2.md and workshop notes naming the course file and keeping
  the complete first answer. A request for missing evidence is a valid answer.
- Block 4: agent-v3.md and the grounded answer and comparison in the notes.
  Verify a citation against its source and identify a remaining human check.
- Block 5: agent-v4.md and the team report in the notes. Find your agent's
  contribution; role-playing a team is not an independent review.
- Block 6: a confirmed collection link, or a reviewed local copy with a
  permission owner and follow-up date. A submitted form is not confirmation.
- Block 7: a saved final 30-day plan after partner review, or self-review
  against the worked example. Keep unknown approvals and measures pending.

Browser participants keep a local document named workshop-notes. VS Code
uses `my-agent/workshop-notes.md`; the commands ask before writing.
Agent versions are kept inside `my-agent/history/` in VS Code. If a save
fails, stop and keep a manual copy before continuing. Never replace an old
history file; repeated runs use a new suffix.

## Resume after an interruption

1. Reopen your latest saved agent and workshop notes.
2. In the approved assistant or Copilot Chat, provide the complete agent,
   current block number and chosen course filename.
3. Before block 4, also provide the actual block-3 answer. If it is lost,
   mark the comparison incomplete rather than inventing what happened.
4. Repeat the current block's prompt or command. Check that the assistant
   identifies the right agent and file before continuing.

If a message is too long, a new conversation may not change that limit.
Do not remove evidence to force it through. Use the written route below
or ask a helper about a tested, approved assistant. If no approved option
works, do not bypass campus policy.

## Written-example route: no AI or account required

Use Maria's alternate-format-planner example in the kit's `examples`
folder, or its online page at
letitglow.app/ahg/kit/examples/maria-alternate-format-planner.md.
Download or print it before the day if you need to work offline.
Use Word, a plain-text editor or paper. Label all outputs "written-example
exercise"; do not claim that you ran an assistant or an independent team.

1. Ready: open the example and create a local notes document. Save and reopen
   it, or use paper. You need no GitHub account.
2. Design: read Maria's six answers in section 2. Write your own one-task
   description, safe input, output and reviewer role using those questions.
   Save it as agent-v1.md, or label the paper copy version 1.
3. Try: read section 4's intentionally flawed first answer. Mark one
   unsupported claim and write the request for evidence you would prefer.
   Keep that answer in notes labeled "sample answer, not my AI run". Add
   the evidence-request instruction to a new agent-v2.md; retain version 1.
4. Ground: compare that answer with the evidence and revised answer in
   section 4. Match one claim to the evidence and one criterion to its
   source. If offline, mark external citation verification pending.
   Save the comparison in notes and one improved review instruction in
   agent-v3.md, retaining versions 1 and 2.
5. Team: read section 5. Identify your specialist's contribution and where
   a person checks the combined report. Write one improved review instruction.
   Save the adapted report in notes and the new agent-v4.md without
   replacing earlier versions. Reopen each file, or check its paper label.
6. Share: keep your work locally. Record whether sharing is approved,
   who can confirm it and the next date; public posting is not required.
7. Plan: adapt section 7 using workflow, handoff, partner, safeguard,
   approved tools/data, first step, approval and day-30 measure. Review
   with a partner, correct one unclear handoff and save the final plan.

At the next block time, rejoin the matching numbered step above. A helper
can read it with you; the written steps remain available without one.
