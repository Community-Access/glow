# Accessibility Agents at AHG 2026

This is the home of "Accessibility Agents: Building Human-Centered AI
Workflows for Trusted Accessibility Automation at Scale", a full-day
workshop at Accessing Higher Ground, Monday 16 November 2026, in Denver.

People who work in higher education accessibility come in with a problem
and leave with an accessibility agent of their own, written in plain
English, grounded in real evidence, working inside a team of agents, and
shared here with their name on it.

## If you are taking the workshop

Everything starts at the setup page: `https://letitglow.app/workshop/ahg-2026`.

1. Follow the four setup steps there. About 20 minutes, no code.
2. Share your practice agent, using the share page. It takes one form and
   one button, and you get a reply here within about a minute.
3. On the day, you will do the same with your real agent.

Stuck at any point? Write to support@community-access.org. A person answers.

## Sharing an agent

You do not need to know Git, and you never make a fork or a pull request.

1. Open the share page: `https://letitglow.app/workshop/ahg-2026/share`.
2. Choose your agent file. The page fills in a short form here on GitHub.
3. Check the workshop code, tick the privacy box, and press Submit new issue.

A reply arrives on that page within about a minute. Either your agent is in,
with a link to it and your name on it, or the reply says exactly what to fix.
To fix something, edit the issue and save; it is checked again straight
away.

Your agent is committed in your name, so it shows on your own GitHub
profile.

## What is here

The table lists each folder and what it holds.

| Folder | What it holds |
|---|---|
| `agents/` | Every agent shared on the day, one folder per person, and the gallery in `agents/README.md` |
| `practice/` | Practice agents shared before the day |
| `kit/` | The agent kit: open this folder in VS Code. The same kit downloads from the setup page |
| `.github/` | The share form and the automation that adds each agent |
| `scripts/` | The script that sends every agent to the Accessibility Agents project |

## Where the agents go next

At the end of the day, every agent in `agents/` goes into the open-source
[Accessibility Agents](https://github.com/Community-Access/accessibility-agents)
project, in its `community/ahg-2026/` folder, with each author credited as
a co-author of that contribution.

## Two rules

1. Nothing private goes into any agent: no student names, records,
   accommodation details or health information. The share form checks for
   the obvious ones.
2. Every agent ends with a person checking its work.
