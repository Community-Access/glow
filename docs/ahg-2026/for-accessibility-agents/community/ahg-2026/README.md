# AHG 2026 workshop agents

Agents written by participants at "Accessibility Agents: Building
Human-Centered AI Workflows for Trusted Accessibility Automation at Scale",
Accessing Higher Ground, Denver, 16 November 2026.

Each folder holds one agent, as a `SKILL.md` in the same format as the skills
in `skills/`, written by someone who works in higher education
accessibility. Most authors were writing their first agent, and most had
never opened a pull request before. Be kind in review.

These are community contributions. They are not loaded by the installer and
are not held to the context budgets in `budgets.json`. The best of them may
be adapted into `skills/` later, with their authors credited.

## What every agent here has

- A role, a task, trusted guidance it cites, an output format, and a named
  human review step.
- A "Never" section: no student information, never "compliant", never a
  finding without evidence.
- An `author` line in its frontmatter.

## Reviewing a pull request here

Merge if the file is a single `SKILL.md` in its own folder, has the six
sections and an author, and contains nothing private. Anything else is a
conversation, not a rejection.
