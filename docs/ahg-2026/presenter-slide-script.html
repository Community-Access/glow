Show: Run /design-my-agent in Copilot Chat, or use the block 2 browser text. Follow the assistant's actual prompts; if it phrases or orders them differently, identify each of the six answers as it arises. Read the following aloud and enter the corresponding answer:

  1. Role: "Who is this agent, and who does it work for? Maria's is an alternate format planner working for a disability resource specialist."
  2. Task: "What one job does it do, and what does it need? Given a checker report and a generic format requirement, it drafts a plan for producing those formats."

  4. Output format: "What should come back? Maria wants a short problem statement, numbered steps with responsible roles, formats to deliver and a review checklist."
  5. Example: "What does a useful answer look like? For a scanned reading, obtain clean text first, check it against the original, then prepare large print and audio."

Participants can proceed at their own pace if their assistant is ahead or behind. Helpers sit with anyone stuck; nobody must speak publicly.

If the room needs help, use these follow-ups as each question comes up:

  1. Role: "Imagine explaining this to a new colleague. What kind of helper is it, and whose work is it helping? Start with: 'You are a ... working for ...'"
  2. Task: "Pick one job you could describe in a sentence. What will you give it, and what should it draft? Start with: 'Given ... produce ...' You can narrow a larger job later."
  3. Trusted guidance: "What reliable standard or approved procedure would a person consult for this job? Name what you know; it is fine to write 'verify the specific criterion' rather than guess. Do not paste a private procedure."
  4. Output format: "Imagine receiving the result on a busy day. Would a short email draft, numbered plan or list of findings help? What headings or details should it contain?"
  5. Example: "Show the shape of one good answer, even in two sentences. Use a fictional case; it is a model of the response, not evidence about a real file."
  6. Human review: "Which role checks the draft, what do they compare it with, and who decides before it goes out? You can name a role rather than a person."
