Supported: Word, Excel, PowerPoint, PDF, Markdown, ePub, images (JPG, PNG, GIF, etc.){% if ai_whisperer_enabled %}, audio (MP3, WAV, M4A, OGG, FLAC, AAC, Opus, WebM, MP4, MPEG, MPGA){% endif %}. Maximum file size: 500 MB.

What can I do with my file?
  • Audit: Check for accessibility compliance issues across Word, Excel, PowerPoint, PDF, Markdown, ePub, and image files.
  • Fix: Auto-fix accessibility problems in Word documents (fonts, sizes, spacing, alignment, emphasis).
  • Convert: Transform documents into Markdown, HTML, PDF, Word, ePub, DAISY, and other formats. For Word documents, also includes a CMS Fragment option for pasting into WordPress or Drupal. Supported image flows can use AI-assisted descriptions when enabled.
  • Speech: Convert uploaded document text into speech audio, preview first sentences, and download full narration with your saved voice settings.
  • Document Chat (when enabled): Ask grounded questions about uploaded document content using accessibility-aware tooling and OpenRouter-backed reasoning.
  • Create Template: Generate a ready-to-use Word template (.dotx) with all ACB formatting pre-configured.
  • BITS Whisperer (when enabled): Transcribe audio (MP3, WAV, M4A, OGG, FLAC, AAC, Opus, WebM, MP4, MPEG, MPGA) to Markdown or Word with retention controls and secure cleanup.
