Use this page before the day, with step card 0: choose a path, set it up, and run the ready check. Then, on Monday 16 November at 10:30 Mountain Time, block 1 starts in Matchless and you follow your path all day.

The day is the same whichever path you take: the same seven blocks, the same learning goals: an agent, an evidence-based team report and a plan. Share publicly only if approved; otherwise keep your reviewed work locally. Pick a campus-approved path that suits your laptop and how you like to work. Before switching, save your agent and exercise notes using the steps below.

No approved AI or account? Follow the written-example route in Word or on paper. This teaches the same review decisions without claiming that an assistant ran. A browser is not a way around campus policy.

Not sure? Take the browser path. It has the least to set up, and your agent is just as real.

The browser path

Everything happens in your web browser. Each block has one text on the browser path page: copy it, paste it into your assistant as one message, and answer its questions. Step cards have every key, under "In a browser".

Set it up: about 10 minutes

  1. Choose an assistant your campus permits. A GitHub account is needed only if you choose GitHub Copilot or approved public sharing.
  2. Choose your assistant from the list below, open it, and sign in. Signing in matters: ChatGPT without an account stops after a message or two.
  3. Turn off training, using the steps for your assistant below. Optional, and a good habit.
  4. Open block 1 on the browser path page, copy the text, paste it into your assistant, and press Enter. Save and reopen the practice file when asked. Confirm its seven headings before setup is complete.
  5. Optional, only if public sharing is approved: open the share page, press "Fill in the practice template", then "Open the share form on GitHub". Opening the form sends the text to GitHub before submission. Otherwise keep practice-SKILL.md locally. Sharing is not a readiness requirement.

ChatGPT

The assistant the browser path was rehearsed in. Accounts and screen reader setups differ, so run the block 1 ready check on your own account and laptop before the day.

  1. Go to chatgpt.com and choose "Sign up for free", or "Log in" if you have an account.
  2. To turn off training: open your profile menu, then Settings, then Data controls, and turn off "Improve the model for everyone".
  3. Use an ordinary chat, not a Temporary Chat, so your conversation is still there after lunch.
  4. A long block text may arrive as an attached file called "Pasted text", with the message box still empty; your screen reader may call the box empty. Wait a moment after pasting, then press Enter. If pressing Enter does nothing, press it again. You will know it was sent when your assistant starts answering.

Free account limits can interrupt the exercises. Save your latest agent; a helper can help you continue with a written example or another campus-approved assistant. The prepared Accessibility Agents prompts need a successful paste and response check on your account. No public directory listing or connector is required for this path.

GitHub Copilot on github.com

Uses the same GitHub account you share with, so there is one account for the whole day.

  1. Go to github.com/copilot and sign in to GitHub. Copilot Free needs no other setup.
  2. Copilot Free has a monthly allowance. If it runs out during the day, save your latest agent and use another campus-approved assistant, or a written example with a helper.

Claude

  1. Go to claude.ai and sign up or log in.
  2. To turn off training: open the menu with your name, then Settings, then Privacy, and turn off "Help improve Claude".
  3. Free-plan limits may interrupt the day. Save your agent and notes before switching to another approved assistant, or use the written-example route. Limits and menus may change.

Gemini

  1. Go to gemini.google.com and sign in with a Google account.
  2. To stop chats being kept: open Settings and help, then Activity, and turn off Keep Activity.

Microsoft 365 Copilot Chat, or your campus assistant

  1. Go to m365copilot.com and sign in with your work or school account.
  2. With a work or school account, enterprise data protection applies, and your campus may log what you type. That is why the rule is the same everywhere: nothing private, ever.
  3. If your campus has its own assistant, use it the same way: one conversation, paste each block's text.

VS Code on your computer

VS Code is a free editor from Microsoft, with GitHub Copilot built in. The kit opens in it as a folder, and each block is a command you type into Copilot Chat. This is the path the program describes: building agent teams with VS Code, GitHub and Copilot. Step cards have every key, under "In VS Code".

Set it up: about 25 minutes

  1. Make a free GitHub account at github.com, if you do not have one.
  2. Install VS Code from code.visualstudio.com. On Windows it installs without administrator rights. You need version 1.143 or later; Help, then About, shows yours.
  3. Sign in: in VS Code, open the Accounts menu at the bottom of the left-hand bar, and choose to sign in with GitHub. An account with no Copilot plan is put on Copilot Free automatically.
  4. Import the AHG 2026 profile: open File, then Preferences, then Profiles. Open the menu on the New Profile button, choose Import Profile, paste {{ profile_url }}, and choose Create. It makes the text larger and turns on screen reader support. If pasting the address does not work, download the AHG 2026 profile file, choose Select File instead, and pick the downloaded file.
  5. Download the agent kit, unzip it, and open the folder: File, then Open Folder.
  6. If a banner says Restricted Mode, choose Manage, then Trust. It is the workshop kit, and Copilot cannot work on its files until you trust it.
  7. Open Copilot Chat: Control+Alt+I on Windows, or Control+Command+I on a Mac. Type /ready-check and press Enter. Confirm command discovery, then allow the expected practice-file write and reopen it. If the command is missing, ask a helper before continuing.
  8. Only if public sharing is approved, practice on the share page. Check the file first: opening the GitHub form sends its text before submission. Otherwise keep the saved practice file locally.

Keys worth knowing

  • Read Copilot's whole answer in a plain text view: Alt+F2 on Windows, Option+F2 on a Mac.
  • Accessibility help for the chat: Alt+F1 on Windows, Option+F1 on a Mac.
  • Start a new chat: the New Chat button at the top of the Chat view.
  • Move between parts of the window: F6.

VS Code for the Web

VS Code running in your browser at vscode.dev, with nothing to install. This path requires command discovery, Copilot access and permission to read and write the kit folder. Verify those in the ready check; do not assume desktop features work identically in a browser. It needs Chrome or Edge: Safari and Firefox cannot open a folder from your laptop. Step cards have every key, under "In VS Code"; use the browser-specific setup and recovery here.

Set it up: about 15 minutes

  1. Make a free GitHub account at github.com, if you do not have one.
  2. Download the agent kit and unzip it. On Windows, open the zip and choose Extract all. On a Mac, open the zip and it unzips itself.
  3. In Chrome or Edge, go to vscode.dev.
  4. Choose Open Folder, and pick the unzipped ahg-2026-agent-kit folder. The browser asks whether vscode.dev may see the files, and later whether it may save changes. Allow both: that is how your agent is saved into the kit.
  5. Sign in: open the Accounts menu at the bottom of the left-hand bar, and choose to sign in with GitHub.
  6. Open Copilot Chat: Control+Alt+I on Windows, or Control+Command+I on a Mac. Type /ready-check and press Enter. Confirm that the command runs, writes the practice copy, and that you can reopen that saved file. If commands or writes are unavailable, use an approved browser assistant or the written-example route with a helper.
  7. Only if public sharing is approved, practice on the share page. Opening the GitHub form sends the file text before submission. Otherwise keep your practice local.

Good to know in the browser

  • Some keys belong to the browser first. Control+N opens a new browser window, not a new chat: use the New Chat button in the Chat view instead.
  • The AHG 2026 profile is for VS Code on a computer. In the browser, the kit's own settings still give you larger text.
  • Keep the vscode.dev tab open all day. If you close it, open vscode.dev again and choose the kit from Open Recent.

Switching paths during the day

First save the latest agent, current block, chosen course filename and actual first answer, grounded comparison or report in your workshop notes. If the first answer is lost, mark the before-and-after comparison incomplete; do not reconstruct it as a result. A new conversation does not necessarily solve a per-message size limit.

  • From VS Code to the browser path: copy all of my-agent/SKILL.md into an approved assistant, supply the block, filename and saved notes, then paste that block's text.
  • From the browser path to VS Code: complete the VS Code ready check first. Preserve any existing agent in my-agent/history/, then paste your latest complete agent into my-agent/SKILL.md and save it. Copy your exercise notes into my-agent/workshop-notes.md. Tell Copilot the current block and filename before resuming.
  • Copilot allowance used up: use another campus-approved assistant or the written-example route, from the same block.

Test your own setup before the day

Every account, browser and screen reader behaves a little differently, so nothing on this page can promise your exact setup works. On the laptop you will bring, run the ready check, save and reopen the practice file, and paste one long block text. If a step does not work with your screen reader or settings, write to jeffbis@arizona.edu or come to the setup table from 10:00 on the day. Helpers note what was blocked and find you a route that works.

The two rules, on every path

  1. Never paste anything private into any AI: student records, health or disability information, or private identifying details. We use a fictional course all day.
  2. Every agent ends with a person checking its work.
