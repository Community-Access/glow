{#- The Copy buttons on the AHG pages. Each button names the textarea it copies (data-copy) and the status region that says what happened (data-status). The text always lives in a real, readable textarea inside a details element, so a person can read it before pasting, and so the fallback can select it when the browser refuses the clipboard. The status region itself stays in the page, empty and unstyled; each message is a new child paragraph, so screen readers hear a change to a region they already know about. Buttons start hidden and appear only when this script runs, so nobody meets a button that does nothing. -#}
