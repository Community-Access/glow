Accessibility Agents: Building Human-Centered AI Workflows for Trusted Accessibility Automation at Scale. A full-day workshop at Accessing Higher Ground, Monday 16 November 2026, 10:30 AM to 4:30 PM Mountain Time.

You will design your own accessibility agent, add it to a team of agents that works through a whole course, and contribute it to an open-source project with your name on it. You do not need to be a developer.

Before the day: four steps, about 20 minutes

  1. Make a free GitHub account at github.com, and turn on Copilot Free in your GitHub settings.
  2. Install VS Code from code.visualstudio.com. On Windows it installs without administrator rights.
  3. Import the AHG 2026 profile. In VS Code, open the Command Palette (Control+Shift+P on Windows, Command+Shift+P on a Mac), type Profiles: Import Profile, and paste this address: {{ profile_url }}. Or download the AHG 2026 profile file and import that.
  4. Download the agent kit (a zip file), unzip it, and open the folder in VS Code. Then open Copilot Chat and type /ready-check.

Stuck? Write to support@community-access.org, or come to the setup table outside the room from 10:00 on the day.

On the day

  • Share your agent: opens GitHub with your agent filled in, ready for your pull request.
  • The slides, with speaker notes, in a reading mode for screen readers.
