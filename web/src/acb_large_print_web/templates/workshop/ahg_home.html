Accessibility Agents: Building Human-Centered AI Workflows for Trusted Accessibility Automation at Scale. A full-day, hands-on workshop at Accessing Higher Ground, Monday 16 November 2026, 10:30 AM to 4:30 PM Mountain Time, in Matchless at the Hilton Denver City Center.

Bring a Windows or Mac laptop, and headphones if you use a screen reader. You do not need to be a developer, and you do not need to have used VS Code or GitHub before. Every step comes with a step card and a helper.

What you will do

  1. Design your own accessibility agent, in plain English, for a real problem from your job.
  2. Put it to work with GitHub Copilot, or the AI assistant you already use, on a sample course full of real barriers.
  3. Ground it in evidence from GLOW, axe and Accessibility Insights, so it cites WCAG 2.2 instead of guessing.
  4. Share it with one form and one button, with your name on it.
  5. Add it to a team of agents that works through the whole course.
  6. Leave with a 30-day plan for your own campus.

Before the day: a short survey

Five minutes, so we have the right things ready for you at 10:00: your path, what your laptop and campus allow, and any access needs. Answer the survey.

Get ready: choose a path

There are three paths into the same day. Each one ends with your own agent, a team report on the whole course, and your agent shared on GitHub with your name on it. Choosing a path compares them and has every setup step. Step card 0 has every click.

  • The browser path: nothing to install. Use ChatGPT, Copilot on github.com, Claude, Gemini or your campus assistant, and paste one text per block from the browser path page. About 10 minutes to set up. Not sure? Take this one.
  • VS Code on your computer: install VS Code, import the AHG 2026 profile, open the kit, and type one Copilot command per block. About 25 minutes.
  • VS Code for the Web: the same VS Code and Copilot in Chrome or Edge at vscode.dev, with the kit opened from your laptop and nothing to install. About 15 minutes.

Whichever you choose, finish setup the same way:

  1. Make a free GitHub account at github.com, if you do not have one. Everyone needs it to share.
  2. Run the ready check: block 1 on the browser path page, or /ready-check in Copilot Chat in VS Code.
  3. Share your practice agent: open the share page, press "Fill in the practice template" (or choose my-agent/SKILL.md from the kit), and press the button. GitHub replies within about a minute. That is the whole of sharing; on the day you do it once more with your real agent.

For both VS Code paths: download the agent kit (a zip file) and unzip it. The browser path does not need it.

The AHG 2026 profile, for VS Code on a computer: in VS Code, open File, then Preferences, then Profiles, open the menu on the New Profile button, choose Import Profile, and paste {{ profile_url }}. Or download the AHG 2026 profile file and import that.

Stuck? Write to support@community-access.org, and a person answers. On the day, the setup table outside the room opens at 10:00.

The kit, online

Every file in the agent kit, readable online: the step cards, the ready-made agents, the office team and the Copilot commands, each with a plain-text address you can paste into Copilot or any AI. Nothing to unzip to look around.

The sample course

PSY 101, the sample course: the web page and documents everyone works on, with barriers planted on purpose, and each one's checker report. Online, so you can run axe or Accessibility Insights on a real address. The same files are in the kit.

Share your agent

  • The share page: choose your agent file, press one button, and GitHub fills in the form for you.
  • The collection: every agent shared at AHG 2026, with its author.
  • The workshop repository: the kit, the collection, and how it all works.

At the end of the day every agent in the collection goes into the open-source Accessibility Agents project, with each author credited.

The two rules

  1. Never paste anything private into any AI: student records, health or disability information, or anyone's name. We use a sample course all day.
  2. Every agent ends with a person checking its work.

Access

Large print, a particular seat, a pause, a repeat: ask for any of it, before or during. That is not an interruption of this workshop; it is the point of it. Write to support@community-access.org any time.
