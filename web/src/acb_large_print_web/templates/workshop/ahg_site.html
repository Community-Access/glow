Check the web page yourself

The course announcement is a real web page at a real address, so the same checkers you use at work run on it.

  1. Open the course announcement.
  2. Run Accessibility Insights for Web, FastPass, or the axe DevTools extension, on that page.
  3. Compare what you find with its checker report above. They use the same engine, axe-core.

The documents work the same way: open the syllabus in Word and choose Review, then Check Accessibility. Step card 4 has the details.
