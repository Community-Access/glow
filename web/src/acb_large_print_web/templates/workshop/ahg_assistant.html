This is the browser path: the whole day in a web browser, with the AI assistant you already have. Every block has one text. You copy it, paste it into your assistant as one message, and answer its questions. It runs the block exactly as the VS Code command does, and you finish with the same agent, the same team report and the same plan.

Tested with ChatGPT, signed in to a free account. It also works with GitHub Copilot on github.com, Claude, Gemini and Microsoft 365 Copilot Chat, including the one your campus provides. Setting up your assistant has the steps for each, and how to stop your chats being used for training.

Before you start

  1. Open your assistant in a second browser tab, and sign in. Signing in matters: ChatGPT without an account stops after a message or two and asks you to log in.
  2. Start one new conversation, and use that same conversation all day. Your agent from block 2 stays in it, so the later blocks can find it.
  3. Never paste anything private: no student names, records, accommodation or health details. We use a fictional course all day.

How every block works

  1. On this page, press the block's Copy button. A message under the button says the text is copied.
  2. Switch to your assistant's tab: Control+Tab, on Windows or Mac.
  3. Move to the message box, where you would type a question. Paste with Control+V on Windows, or Command+V on a Mac.
  4. Press Enter to send. The assistant starts the block, usually by asking you one question.
  5. Answer each question in the same message box. When it gives you something to keep, it puts it in a box with its own Copy button.

Want to read a text before you paste it? Each block has "Read the text first". It is long because it carries the kit's files with it; that is what lets your assistant work from evidence instead of guessing.

If something goes wrong

  • The assistant asks you to log in: sign in or make a free account, then paste the block's text again.
  • The assistant says the message is too long: start a new conversation and paste again. If it still refuses, the free plan's limit is the problem; switch to another assistant, or ask a helper.
  • The assistant has forgotten your agent: paste your agent again as its own message, then paste the block's text.
  • The assistant has used up its free messages for now: switch to another assistant and carry on from this block. Your agent is on your computer, from block 2.
  • Anything else: raise a hand, or write to support@community-access.org.
