This page puts your agent into the open-source Accessibility Agents project, under your own GitHub account, with your name on it. It takes about three minutes. Nothing here is sent anywhere until you press the green button on GitHub yourself.

Lowercase words joined by hyphens, like alternate-format-planner. Filled in from the file when it can be.

What happens on GitHub

  1. GitHub opens a new file, already filled in, in the workshop folder of the Accessibility Agents project.
  2. GitHub says you need your own copy of the project to propose a change. That is called a fork, and GitHub makes it for you.
  3. Scroll to the bottom and press Propose changes.
  4. On the next page, press Create pull request, then Create pull request again.

That is your pull request. Your agent is now part of an open-source project, and it will be merged on the projector this afternoon. Well done.

If anything goes wrong

Raise a hand, or use the ready-made agent you started from in examples/agents/. Every pull request counts, including one that started from an example.
