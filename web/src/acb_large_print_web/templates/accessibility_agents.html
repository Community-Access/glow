Accessibility Agents is an open-source team of accessibility specialists for AI assistants. Each one checks work against WCAG 2.2 AA and names the success criterion, the severity and the fix for every problem it finds. Here are the ways to use it, and a place to run its checks right now.

Ways to use Accessibility Agents

  • In your AI assistant, with real checks. Connect ChatGPT, Claude or VS Code to the Accessibility Agents server using the connection steps. The public server checks information you submit and can scan a document you send or share by public link; it cannot reach into your computer. GLOW's own chat offers a separate upload option.
  • In any assistant, by pasting. The texts on the AHG assistant prompts carry an entry point and its specialists. Paste one as your first message, then give it your checker's results. A free account is enough; no directory listing or connector setup is required.
  • For documents. Upload a Word, Excel, PowerPoint, Markdown, PDF or ePub file to GLOW's audit for a full report, then fix it with GLOW.
  • Installed on your computer. The local package can run scanners on your files after optional dependencies are installed. Review hooks work only in clients that support them. The Codex plugin includes skills and server tools, but not review hooks; see the Accessibility Agents installation guide.

Connect your AI assistant

Connecting your own assistant is the richest way to use Accessibility Agents: your assistant does the thinking on your own account, and it calls the Accessibility Agents server whenever it needs a real measurement instead of a guess. Nothing is paid for by you on our side, and nothing needs a sign-in.

The server's address, for every assistant below:

{{ hosted_mcp_url }}

The public connector offers twelve tools. Eight check colors, text, HTML and component guidance: WCAG and APCA contrast, color-vision simulation, reading level, guidelines, headings, link text and form labels. Four more scan Word, Excel, PowerPoint, PDF, ePub, Markdown and HTML files; provide specialist instructions; extract pictures from documents; and add alt text to supported files. Send file contents or a public sharing link for documents up to 20 MB. Use a public link only for a file you are allowed to share with anyone who has the link. The server stores a temporary copy while it works and deletes it before answering; a file with alt text added is available through a download link for one hour. It cannot reach into your computer. Follow your institution's data rules before sending files or making a sharing link. GLOW's own chat above offers a separate upload option; local scanners are another option when you install the package on your computer.

To scan a document, ask your assistant to review the file and attach it if the app can send attachments to connectors. If it cannot, use a public sharing link. Read how file handling works.

ChatGPT, as a connector

You need: a paid ChatGPT plan (Plus, Pro, Business, Enterprise or Edu). On Business, Enterprise and Edu plans an administrator may have to allow custom connectors first. OpenAI moves these settings now and then, so the names may differ slightly.

Turn on Developer mode

  1. Open ChatGPT and go to Settings.
  2. Open Apps and Connectors. It may be called Connectors or Apps.
  3. Open Advanced settings and turn on Developer mode. If it is not there, look under Settings, Security.

Add Accessibility Agents

  1. Back in Apps and Connectors, choose Create. It may say Add custom connector.
  2. For Name, type Accessibility Agents.
  3. For Description, type WCAG 2.2 AA checks and document accessibility tools.
  4. For MCP server URL (the remote tool connection), enter {{ hosted_mcp_url }}.
  5. For Authentication, choose No authentication.
  6. Check the box saying you trust this application, then choose Create.

Use it in a chat

  1. Start a new chat and open the tools menu: the plus button beside the message box.
  2. Choose Developer mode or the list of connectors, and turn on Accessibility Agents.
  3. Ask something that needs a check, such as Does #767676 text on a white background pass WCAG AA?
  4. The first time, ChatGPT asks before calling the tool. Allow it.

If it does not work

  • No Developer mode: your plan may not include it, or an administrator has turned it off.
  • ChatGPT answers without calling the tool: say use the Accessibility Agents connector in your request.
  • An error about the server: check that the server's health page says "status":"ok".

Claude, on the web, desktop or phone

You need: a Claude account. On Team and Enterprise plans an owner may need to add the connector for the organization first.

  1. Open Claude and go to Settings, then Connectors.
  2. Choose Add custom connector.
  3. For Name, type Accessibility Agents.
  4. For URL, enter {{ hosted_mcp_url }}, then choose Add.
  5. In a chat, open the tools menu and check that Accessibility Agents is turned on.
  6. Ask something that needs a check, such as Check the headings in this HTML, and paste the HTML.

This custom connector is separate from Claude's plugin directory. As of 6 November 2026, the full plugin submission was refused under directory policy; follow-up on a skills-only version is still pending. This does not affect using the connector or the workshop's browser path.

Claude Code

Most Claude Code users want the full plugin, which includes these checks and the scanners that read files on your own computer:

/plugin marketplace add Community-Access/accessibility-agents
/plugin install accessibility-agents@community-access

To add only the hosted checks, run this in a terminal:

claude mcp add --transport http accessibility-agents {{ hosted_mcp_url }}

VS Code with GitHub Copilot

Add this to .vscode/mcp.json in your project, or to your user MCP configuration from the command palette with MCP: Open User Configuration:

{
  "servers": {
    "accessibility-agents": {
      "type": "http",
      "url": "{{ hosted_mcp_url }}"
    }
  }
}

Then open Copilot Chat in agent mode and choose the tools button to check that the Accessibility Agents tools are on.

Any other assistant

Any assistant that can add a remote MCP server over HTTPS can use Accessibility Agents. Look for a setting called connectors, MCP servers or tools, and give it {{ hosted_mcp_url }} with no authentication.

If your assistant cannot add a server, paste one of the texts from the AHG assistant prompts instead. You get the specialists without the measurements.

The hosted server guide on GitHub has the same steps.

What the checks send

Checks send the colors, text, HTML or component name you enter to the Accessibility Agents server. Document tools send the file contents, or a public sharing link that the server fetches. Follow your institution's data rules before sending files or making a sharing link. The server accepts files up to 20 MB, keeps a temporary copy while it works, then deletes that copy before answering. A file with alt text added is kept behind its download link for one hour, then deleted. The server does not access files on your computer unless you send the file or a link.

In GLOW's own chat, your question, pasted content, file text, scanner report, image you ask it to describe and key go through GLOW for the request; GLOW sends the content to the AI provider you chose and runs any requested checks. GLOW keeps none of it. Your provider's own terms cover what it does with your question and content. GLOW's own privacy policy covers the rest of this site.
