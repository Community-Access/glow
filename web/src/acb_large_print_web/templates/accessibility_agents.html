Accessibility Agents is an open-source team of accessibility specialists for AI assistants. Each one checks work against WCAG 2.2 AA and names the success criterion, the severity and the fix for every problem it finds. Here are the ways to use it, and a place to run its checks right now.

Check something now

These checks run on the Accessibility Agents server. No account and no AI are needed, and the answer is the same every time.

Color contrast

Ask a question with your own AI

Ask Accessibility Agents anything, such as Is this form accessible? or Explain 1.4.3 for my button, and paste the HTML, text or colors it should look at. The answer comes from your own AI account, which can run the same checks as above while it works.

  • You pay your provider, not us. Each question uses your key's credit. Google Gemini and OpenRouter both offer free models.
  • Your key stays in this tab. It is kept only until you close this tab or your browser, and it goes away then. GLOW passes it to your provider with each question and never stores it.

Ways to use Accessibility Agents

  
    
    
  • In your AI assistant, with real checks. Connect ChatGPT,
      Claude or VS Code to the Accessibility Agents server, as described
      below. Your own AI account does the thinking;
      the server runs the checks.
    • 
    
  • In any assistant, by pasting. The texts on
      the AHG assistant page carry an entry point and
      its specialists. Paste one as your first message, then give it your
      checker's results. A free account is enough.
    • 
    
  • For documents. Upload a Word, Excel, PowerPoint,
      Markdown, PDF or ePub file to GLOW's
      audit for a full report, then fix it
      with GLOW.
    • 
    
  • Installed in full. The full plugin adds review hooks
      that stop an AI from changing a page before the accessibility review
      runs, and scanners that check files on your own computer. It installs
      in Claude Code, GitHub Copilot, Codex and Gemini CLI; see
      the
      Accessibility Agents README.
    • 
  






  
Connect your AI assistant

  
Connecting your own assistant is the richest way to use Accessibility
  Agents: your assistant does the thinking on your own account, and it calls
  the Accessibility Agents server whenever it needs a real measurement instead
  of a guess. Nothing is paid for by you on our side, and nothing needs a
  sign-in.

  
The server's address, for every assistant below:

  
{{ hosted_mcp_url }}

  
Choose your assistant to see its steps. Each section opens and closes
  with Enter or Space.


  

    
ChatGPT, as a connector

    
You need: a paid ChatGPT plan (Plus, Pro, Business,
    Enterprise or Edu). On Business, Enterprise and Edu plans an administrator
    may have to allow custom connectors first. OpenAI moves these settings now
    and then, so the names may differ slightly.

    
Turn on Developer mode

    
    
      
  1. Open ChatGPT and go to Settings.
    2. 
      
  2. Open Apps and Connectors. It may be called Connectors or Apps.
    3. 
      
  3. Open Advanced settings and turn on Developer mode. If it is not
        there, look under Settings, Security.
    4. 
    

    
Add Accessibility Agents

    
    
      
  1. Back in Apps and Connectors, choose Create. It may say Add custom
        connector.
    2. 
      
  2. For Name, type Accessibility Agents.
    3. 
      
  3. For Description, type WCAG 2.2 AA checks for contrast,
        reading level and HTML.
    4. 
      
  4. For MCP server URL, enter {{ hosted_mcp_url }}.
    5. 
      
  5. For Authentication, choose No authentication.
    6. 
      
  6. Check the box saying you trust this application, then choose
        Create.
    7. 
    

    
Use it in a chat

    
    
      
  1. Start a new chat and open the tools menu: the plus button beside the
        message box.
    2. 
      
  2. Choose Developer mode or the list of connectors, and turn on
        Accessibility Agents.
    3. 
      
  3. Ask something that needs a check, such as Does #767676 text on a
        white background pass WCAG AA?
    4. 
      
  4. The first time, ChatGPT asks before calling the tool. Allow it.
    5. 
    

    
If it does not work

    
    
      
  • No Developer mode: your plan may not include it, or an administrator
        has turned it off.
    • 
      
  • ChatGPT answers without calling the tool: say use the
        Accessibility Agents connector in your request.
    • 
      
  • An error about the server: check that
        the server's health page says
        "status":"ok".
    • 
    

  


  

    
Claude, on the web, desktop or phone

    
You need: a Claude account. On Team and Enterprise
    plans an owner may need to add the connector for the organization
    first.

    
    
      
  1. Open Claude and go to Settings, then Connectors.
    2. 
      
  2. Choose Add custom connector.
    3. 
      
  3. For Name, type Accessibility Agents.
    4. 
      
  4. For URL, enter {{ hosted_mcp_url }}, then choose
        Add.
    5. 
      
  5. In a chat, open the tools menu and check that Accessibility Agents is
        turned on.
    6. 
      
  6. Ask something that needs a check, such as Check the headings in
        this HTML, and paste the HTML.
    7. 
    

    
The full Accessibility Agents plugin is in review for Claude's plugin
    directory. When it is listed, Claude will be able to install the skills and
    this connection in one step.

  


  

    
Claude Code

    
Most Claude Code users want the full plugin, which includes these
    checks and the scanners that read files on your own computer:

    
/plugin marketplace add Community-Access/accessibility-agents
/plugin install accessibility-agents@community-access

    
To add only the hosted checks, run this in a terminal:

    
claude mcp add --transport http accessibility-agents {{ hosted_mcp_url }}

  


  

    
VS Code with GitHub Copilot

    
Add this to .vscode/mcp.json in your project, or to your
    user MCP configuration from the command palette with MCP: Open User
    Configuration:

    
{
  "servers": {
    "accessibility-agents": {
      "type": "http",
      "url": "{{ hosted_mcp_url }}"
    }
  }
}

    
Then open Copilot Chat in agent mode and choose the tools button to
    check that the Accessibility Agents tools are on.

  


  

    
Any other assistant

    
Any assistant that can add a remote MCP server over HTTPS can use
    Accessibility Agents. Look for a setting called connectors, MCP servers or
    tools, and give it {{ hosted_mcp_url }} with no
    authentication.

    
If your assistant cannot add a server, paste one of the texts from
    the AHG assistant page instead. You get the
    specialists without the measurements.

  server guide on GitHub has the same steps.






  
What the checks send

  
A check sends only what you typed into it: two colors, a passage of text,
  some HTML or a component name. It goes to the Accessibility Agents server on
  this site, which reads no files, fetches no web addresses and keeps no
  history.

  
A question you ask, with what you pasted and your key, goes to GLOW, which
  sends it to the service you chose and passes the checks it asks for to the
  Accessibility Agents server. GLOW keeps none of it. Your provider's own
  terms cover what it does with your question. GLOW's own privacy
  policy covers the rest of this site.
